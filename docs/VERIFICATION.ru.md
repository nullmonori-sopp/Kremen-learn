Обычный `cargo test` пропускает проверки пространств имён и не равнозначен этому
запуску. Workflow GitHub подготовлен для воспроизводимой сборки; удалённый CI
в этой работе не запускался.

## Проверка настоящего окна

Установленное приложение открыто на виртуальном экране. В первом уроке код
изменён в Monaco, Ctrl+Enter вывел `Hello, Kremen!` и `I can program.` с кодом 0.
Проверка решения записала `01-first-program` в SQLite. Неизвестная переменная
`missing` дала реальную E107 и маркер редактора; ошибка не сбросила завершение
урока. Прогресс и отредактированный текст сессии сохранились после перезапуска.
Открытие проекта по пути читает настоящий каталог с реализациями модулей и
заголовком `.krh`; проект выполняется в режиме Work.

В среде сборки нет системно установленных dev-пакетов и рабочего стола.
Зависимости распакованы в локальный sysroot без административной установки.
Для GUI-проверки строка каталога helper-процессов локальной библиотеки WebKit
перенаправлена в sysroot, пути D-Bus services — в локальные пакеты. Приложение,
компилятор, тесты и песочница не изменены. Эта настройка тестовой среды не входит
в установщики и не заменяет проверку установки пакетным менеджером на чистой ОС.
Обычной системе нужны перечисленные системные пакеты. Диалог GTK показан, но
автоматический выбор в сеансе без оконного менеджера оказался ненадёжным;
проверенный запасной способ — открытие по пути. Все сочетания desktop portals,
экспорта и импорта в графическом окне не проверялись.

## Сравнение с фотографиями

Из двух фотографий взяты композиционные принципы: неподвижная боковая
библиотека, широкие рекомендации, горизонтальный ряд обложек и нижняя плавающая
панель. У Kremen Learn собственные коралловая геометрия, синие волны, блоки
памяти, зелёные формы ресурсов и янтарные сетки. Изображения и логотипы Apple
не копировались. Обложки используют общие layout identities; нижняя панель и
рабочая область связаны spring-переходом. Учитывается уменьшенное движение,
фоновые CSS-эффекты приостанавливаются в неактивном окне.

Настоящее приложение: `desktop-home.png`, `desktop-run.png`, `desktop-error.png`,
`desktop-project.png`. Браузерные снимки `preview-home.png`, `preview-course.png`,
`preview-lesson.png`, `preview-light.png` отдельно фиксируют 1366×768 и светлую
тему. Это работающие интерфейсы. Проверены фокус и основные горячие клавиши;
полный аудит экранным диктором не проводился.

## Конкретные ограничения

- Нативная Windows-компиляция, изоляция и `.exe`-установщик не реализованы.
  Необязательные PowerShell/WSLg-скрипты просмотрены как исходники и не запущены
  на Windows. Проверенная поддержка Windows не заявляется.
- Пакеты предназначены для Debian 13 x86-64. Другие дистрибутивы, старые glibc,
  ARM и все desktop portals не проверены. Нужны GCC/libc, WebKitGTK/GTK,
  Bubblewrap с разрешёнными namespaces и графический D-Bus-сеанс.
- Лимиты памяти/CPU действуют на процесс, лимит задач — исходное число задач UID
  плюс 128. Нет суммарного cgroup-бюджета и общей квоты диска. Системные файлы
  доступны для чтения; точные границы описаны в модели запуска.
- Сохраняется активная рабочая область; истории черновиков всех рабочих областей
  и интерфейса Git нет. Задержка автосохранения — 700 мс; аварийное закрытие до
  записи может потерять последнее ещё не сохранённое изменение. Перед переходом к урокам сохраняйте изменения проектов
  на диск. Недавний проект перечитывается с диска, конфликт внешнего изменения
  требует выбора вместо перезаписи.
- Резервная копия содержит прогресс/настройки/сессию/записи проектов. Импорт
  восстанавливает прогресс, а не автоматически каждое поле backup. Выполнение и
  экспорт включают `.kr`/`.krh`, без произвольных файлов проекта. Боковая панель
  показывает относительные пути файлов без раскрывающейся иерархии каталогов.
- Продвинутые темы пока представлены расширяемой структурой. Подсказки редактора
  ограничены ключевыми словами, семантического сервера языка нет.
- Пакеты не подписаны и не опубликованы. Подключение GitHub отклонило
  `createRepository`: `Resource not accessible by integration`. Второй удалённый
  репозиторий не создан; локальный Git и архив исходников готовы для публикации
  с необходимыми правами.
