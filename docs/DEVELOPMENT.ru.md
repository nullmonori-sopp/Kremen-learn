# Разработка и сборка пакетов

Первый выпуск предназначен для Linux x86-64. Эти инструкции разработки
описывают Debian 13 и Ubuntu 24.04 с графической сессией. Фактическая проверка
распространяемого пакета фиксируется отдельно в `VERIFICATION.ru.md`;
наличие инструкции для дистрибутива не означает, что готовый файл был проверен
в нём. Нативный Windows-запуск и интеграция WSL пока не являются
реализованными целями выпуска.

## Системные компоненты

Установите C/C++-компиляторы, заголовки WebKitGTK 4.1 и зависимости сборки
Linux-пакета:

```sh
sudo apt-get update
sudo apt-get install -y build-essential curl file pkg-config libssl-dev \
  libgtk-3-dev libwebkit2gtk-4.1-dev librsvg2-dev \
  libayatana-appindicator3-dev patchelf bubblewrap xdg-desktop-portal xdg-desktop-portal-gtk
```

Установите актуальный стабильный Rust через [rustup](https://rustup.rs/) и
Node.js 22 LTS с npm. Версия Rust должна удовлетворять
`src-tauri/Cargo.toml`; для актуальных зависимостей используйте текущий
стабильный выпуск. Python 3 нужен инструментам проверки уроков и установщика,
но не самому Kremen и не установленному приложению.

```sh
rustup toolchain install 1.99.1 --profile minimal --component rustfmt
rustc --version
cargo --version
node --version
npm --version
gcc --version
g++ --version
pkg-config --modversion webkit2gtk-4.1
bwrap --version
```

Bubblewrap также нужны работающие непривилегированные пространства имён
пользователя, процессов и сети. Наличие программы в `PATH` не доказывает
работоспособность изоляции. Панель тулчейна проверяет фактическую готовность.
Контейнер или ограниченная система могут запрещать создание пространств имён;
не отключайте проверки изоляции ради успешного статуса урока.

## Первая сборка

Из корня репозитория:

```sh
npm ci
./scripts/build-toolchain.sh
npm run verify:lessons
npm run build
cargo test --manifest-path src-tauri/Cargo.toml
```

Каталог `vendor/kremen/` содержит зафиксированные исходники языка. Скрипт
сборки копирует настоящий исполняемый файл компилятора и заголовок runtime
в ресурсы настольного пакета. `toolchain.lock.json` указывает исходный коммит.
Уроки проверяются этим компилятором, а не JavaScript-заменой.

`npm run build` синхронизирует учебное содержание и создаёт статический экспорт
Next.js в `out/`. Готовая программа включает эти файлы и локальные ресурсы
Monaco; сервер Node.js или Next.js при обычной работе не запускается.

Запуск окна приложения для разработки:

```sh
npm run desktop
```

Tauri запускает сервер Next.js для разработки и Rust-приложение вместе.
Для работы только над внешним видом выполните `npm run dev` и откройте
`http://127.0.0.1:1420`. Компиляция и файловые операции доступны в окне
Tauri. Браузерный предпросмотр сообщает об этом ограничении и не подменяет
выполнение вымышленными результатами.

## Проверки

```sh
npm run verify:lessons
cargo test --manifest-path src-tauri/Cargo.toml
python3 installer/test_installer.py
```

Проверка уроков собирает настоящие примеры и сравнивает вывод решений.
Нативные тесты проверяют реализованные контракты процессов, диагностики
и сохранения. Тесты установщика собирают небольшие настоящие установщики
и проверяют распаковку, команды запуска и сохранение данных при удалении.
Отчёт о проверке выпуска перечисляет фактически выполненные проверки
и недоступные участки; именно он определяет заявления о поддержке платформ.

## Пакеты выпуска

```sh
npm run package -- --bundles deb
./scripts/build-installer.sh
```

Tauri записывает Debian-пакет в
`src-tauri/target/release/bundle/deb/`. Собственный установщик на C++ и
контрольная сумма находятся в:

```text
artifacts/Kremen-Learn-0.1.0-linux-x86_64.run
artifacts/Kremen-Learn-0.1.0-linux-x86_64.run.sha256
```

Инструкции установщика доступны [по-английски](../installer/README.md) и
[по-русски](../installer/README.ru.md). Он устанавливает программу для
текущего пользователя без прав администратора. В комплект входят приложение,
компилятор, заголовок runtime и уроки. Установщик проверяет системные компоненты,
но не скачивает и не устанавливает их.

Для работы нужны WebKitGTK 4.1, GTK 3, GCC с C11 и POSIX-потоками, заголовки
libc и Bubblewrap. На офлайн-компьютере совместимые системные пакеты должны
быть установлены заранее либо перенесены средствами офлайн-установки вашего
дистрибутива. Указание зависимости в `.deb` не означает её включение в файл
пакета.

Linux-программы зависят от libc и ABI библиотек машины сборки. Для поддержки
старых дистрибутивов собирайте и проверяйте программу в самом старом
поддерживаемом окружении. Сборка только на Debian 13 не доказывает
совместимость с Ubuntu 24.04.

## Повторная сборка без сети

Первая сборка обычно загружает npm-пакеты, Rust crates и системные зависимости
разработки. Если заранее наполнить и сохранить эти кеши, доступны команды:

```sh
npm ci --offline
cargo build --offline --release --manifest-path src-tauri/Cargo.toml
```

После этого интерфейс и тулчейн можно собрать из локальных файлов.
Для упаковки также должны быть заранее установлены необходимые инструменты
Tauri для выбранной платформы. Недостающие кеши и системные пакеты нужно
перенести заранее. Офлайн-работа установленной программы не означает
возможность первой сборки без зависимостей и доступа к сети.

`rust-toolchain.toml` фиксирует Rust 1.99.1. Для включения реальных проверок
компилятора и изоляции: `cargo test --manifest-path src-tauri/Cargo.toml --lib
-- --include-ignored --test-threads=1`. Браузерная проверка статического экспорта:
`node scripts/verify-ui.mjs`; путь к Chromium можно задать через `CHROMIUM_PATH`.
