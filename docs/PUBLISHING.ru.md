# Публикация

[English](PUBLISHING.md) · [Разработка](DEVELOPMENT.ru.md)

Kremen Learn хранится отдельно от репозитория языка. Исходники компилятора
включены на коммите из `toolchain.lock.json`. Кэши сборки, установщики
и локальные пользовательские данные не должны попадать в Git.

## Создать удалённый репозиторий

Из корня проекта, с аккаунтом GitHub, имеющим право создавать репозитории:

```sh
gh repo create nullmonori-sopp/Kremen-Learn --public --source=. --remote=origin --push \
  --description 'An offline desktop studio for learning Kremen: lessons, a code editor and a real local compiler. Free and open source.'
```

Если репозиторий уже существует, сначала проверьте его содержимое. Для пустого
репозитория нужного владельца:

```sh
git remote add origin https://github.com/nullmonori-sopp/Kremen-Learn.git
git push -u origin main
```

Подключение может разрешать чтение и отправку кода, но не создание репозиториев.
Ответ `Resource not accessible by integration` требует изменить права этого
подключения либо создать пустой репозиторий от имени владельца. Такой ответ
не означает, что репозиторий создан.

## Подготовить выпуск

1. Выполните [инструкции сборки](DEVELOPMENT.ru.md), включая нативные тесты
   с `--include-ignored`.
2. Запустите установщик и приложение на каждой заявляемой платформе. Запишите
   среду, результаты и пробелы в [отчёт о проверках](VERIFICATION.ru.md).
3. Согласованно обновите историю изменений и номера версий. Проверьте отсутствие
   пользовательских данных, секретов, кэшей и неподтверждённых заявлений.
4. Публикуйте установщики отдельно от исходников, с SHA-256 и описанием выпуска,
   в котором указаны проверенный дистрибутив и системные зависимости.
   Различайте коммиты исходников и собранных пакетов.

Workflow собирает пакеты Linux и сохраняет их в артефакты запуска. Он не создаёт
выпуск автоматически и не подтверждает поддержку Windows. Архив исходников
должен содержать приложение, уроки, документацию на двух языках и закреплённый
компилятор, без кэшей сборки и пользовательских баз данных.
