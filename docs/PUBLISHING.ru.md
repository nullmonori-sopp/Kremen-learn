# Публикация отдельного репозитория

Проект подготовлен как отдельный локальный Git-репозиторий. Подключение GitHub
отклонило создание `nullmonori-sopp/Kremen-Learn`:
`Resource not accessible by integration (createRepository)`. Удалённый
репозиторий не создан, успешная отправка не заявляется.

После предоставления права создавать репозитории выполните из корня проекта:

```sh
gh repo create nullmonori-sopp/Kremen-Learn --public --source=. --remote=origin --push
```

Если пустой удалённый репозиторий создан отдельно:

```sh
git remote add origin https://github.com/nullmonori-sopp/Kremen-Learn.git
git push -u origin main
```

Перед отправкой в существующий репозиторий проверьте его содержимое. Установщики
исключены из Git и могут быть приложены к релизу вместе с контрольными суммами.
Архив исходников включает зафиксированный компилятор, приложение, уроки и
двуязычные документы, без кэшей сборки и пользовательского прогресса.
