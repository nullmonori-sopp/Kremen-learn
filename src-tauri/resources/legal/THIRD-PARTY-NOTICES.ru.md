# Стороннее программное обеспечение

Kremen Learn распространяется по лицензии MIT, см. [LICENSE](LICENSE).
Компилятор Kremen и runtime: MIT, Copyright (c) 2026 Sopp Andrey.
Оригинальный код и лицензия сохранены в `vendor/kremen/`; лицензия также входит
в устанавливаемый комплект инструментов.

Интерфейс использует React (MIT), Next.js (MIT), Monaco Editor (MIT), Motion
(MIT), Lucide (ISC), react-markdown (MIT). Нативная часть использует Tauri
(MIT OR Apache-2.0), Rust-библиотеки с их лицензиями, SQLite (общественное
достояние) через rusqlite (MIT), rfd (MIT). Точные версии находятся в
`package-lock.json` и `src-tauri/Cargo.lock`.

Системные библиотеки не включены в установщик. WebKitGTK, GTK, libc, GCC и
Bubblewrap поставляются операционной системой со своими лицензиями.
Для компиляции пользовательских программ необходим C-компилятор.

В проект не включены изображения, логотипы и шрифты Apple. Обложки курсов —
оригинальные SVG-композиции, распространяемые вместе с проектом.
