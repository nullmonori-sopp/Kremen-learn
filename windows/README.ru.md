# Экспериментальные скрипты WSLg

[English](README.md)

Скрипты PowerShell 7.3+ устанавливают и запускают **Linux-пакет** в уже
настроенном **Debian 13+ x86-64 под WSL2 с WSLg**. Это не нативное приложение
Windows и не `.exe`-установщик. В данной среде Windows-хоста нет, скрипты
на нём не запускались. Процессы WSL, графика, права, преобразование путей,
пространства имён и файловые диалоги остаются непроверенными участками.

WSL2/WSLg и Debian нужно подготовить самостоятельно. Скрипты не включают
компоненты Windows, не устанавливают и не конвертируют дистрибутив, не
скачивают пакеты и не меняют системные политики. В Debian заранее нужны
WebKitGTK4.1, GTK3, GCC/заголовки libc, Bubblewrap согласно
[инструкции разработки](../docs/DEVELOPMENT.ru.md). WSL должен разрешать
namespaces Bubblewrap. Ошибка проверки прерывает установку или запуск.

Храните три `.ps1` рядом. Linux-установщик `.run` положите рядом либо укажите
его путь. Запускать в PowerShell 7.3+:

```powershell
./Install-KremenLearn.ps1 -Distribution Debian -Installer 'C:\Downloads\Kremen-Learn-0.1.0-linux-x86_64.run'
./Start-KremenLearn.ps1 -Distribution Debian
```

Команды передаются через `wsl.exe --distribution NAME --exec` отдельными
элементами `ProcessStartInfo.ArgumentList`. Пользовательские пути не
подставляются в `bash -c` или выражения PowerShell. Путь установщика
преобразуется `wslpath`, файл копируется в отдельный временный каталог Linux,
проверяется C++-установщиком и устанавливается в `~/.local` Linux-пользователя.
Временный каталог удаляется. Прогресс и проекты хранятся в Linux-дистрибутиве;
Windows-папки не подключаются скрыто к песочнице упражнений.

Для удаления выполните тот же `.run` внутри дистрибутива с
`--uninstall --prefix /home/ИМЯ_LINUX/.local`. См.
[инструкцию установщика](../installer/README.ru.md); данные сохраняются.

Проверка исходника не означает работающую поддержку Windows. До заявления
поддержки нужны реальные Windows-проверки установки, запуска, компиляции,
Stop, диагностики, сохранения, перезапуска WSL, путей с пробелами и кириллицей,
а также файловых диалогов.
