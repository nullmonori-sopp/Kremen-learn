# Ошибка как значение

## Подсказки

1. Проверьте вход перед вычислением успешного результата.

2. При отрицательном значении верните fail(1001).

3. Вставьте if value < 0 { return fail(1001) } перед return ok(...).

## Решение

```kremen
package main
func checkedSquare(value i64) !i64 {
    if value < 0 {
        return fail(1001)
    }
    return ok(value * value)
}
func show(value i64) {
    match checkedSquare(value) {
        ok(answer) => { println("square:", answer) }
        fail(code) => { println("error:", code) }
    }
}
func main() {
    show(3)
    show(-2)
}
```

## Разбор решения

3 приводит к ok(9), а -2 возвращает fail(1001) до умножения. match читает нужное вложенное значение в каждом вызове. Код 1001 относится к договорённости этой задачи. Не передавайте его в errorMessage: эта функция описывает OS errno.

## Связь с другими языками

Rust Result и помеченные значения ошибок в других языках выражают ту же идею: ожидаемая неудача участвует в обычном потоке управления. Go возвращает ошибку отдельным значением; обязанность обработать её остаётся.
