# Последовательность в памяти

## Подсказки

1. Цикл уже считает правильную сумму.

2. Измените копию после var copy = values.

3. Вставьте copy[0] = 99 перед выводом.

## Решение

```kremen
package main
func main() {
    var values = [4]i64{3, 6, 9, 12}
    var total i64 = 0
    for index := 0; index < len(values); index++ {
        total += values[index]
    }
    var copy = values
    copy[0] = 99
    println("total:", total)
    println("original:", values[0], "copy:", copy[0])
}
```

## Разбор решения

Элементы оригинала дают сумму 30. Присваивание создаёт независимое значение. Только первый элемент copy становится 99, а values[0] остаётся равным 3.

## Связь с другими языками

Фиксированные массивы Kremen и Rust — значения. Списки Python и массивы JavaScript ведут себя скорее как ссылки. Всегда выясняйте, копирует ли присваивание данные или разделяет память.
