# Последовательность в памяти

## Цель

Использовать индексы от нуля и понимать копирование массива фиксированного размера.

## Объяснение

Массив хранит фиксированное число значений одного типа. У `[4]i64{3, 6, 9, 12}` индексы от 0 до 3. len возвращает длину. Индекс len уже за границами, поэтому обход использует index < len(values). Kremen проверяет границы. Присваивание массива копирует элементы: изменение копии не меняет оригинал. Срезы, которые появятся позже, описывают общую память.

## Пример

```kremen
package main
func main() {
    var values = [3]i64{2, 4, 6}
    var copy = values
    copy[0] = 9
    println(values[0], copy[0])
}
```

## Задание

Сложите элементы [3, 6, 9, 12]. Скопируйте массив, измените copy[0] на 99, затем выведите `total: 30` и `original: 3 copy: 99`.

## Стартовый код

```kremen
package main
func main() {
    var values = [4]i64{3, 6, 9, 12}
    var total i64 = 0
    for index := 0; index < len(values); index++ {
        total += values[index]
    }
    var copy = values
    println("total:", total)
    println("original:", values[0], "copy:", copy[0])
}
```
