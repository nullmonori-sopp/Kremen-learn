# Представить возможные случаи

## Подсказки

1. Каждая ветвь должна выводить слово своего варианта.

2. Измените ветвь Wait на println("wait").

3. Измените Go на println("go") и сохраните все три ветви.

## Решение

```kremen
package main
type Signal enum {
    Stop
    Wait
    Go
}
func show(signal Signal) {
    match signal {
        Stop => { println("stop") }
        Wait => { println("wait") }
        Go => { println("go") }
    }
}
func main() {
    show(Signal.Stop())
    show(Signal.Wait())
    show(Signal.Go())
}
```

## Разбор решения

Тип допускает ровно три состояния. Каждый вызов выбирает одну ветвь: не нужны условные числовые коды или противоречивые комбинации bool. Явное покрытие удовлетворяет требованию Learn L004.

## Связь с другими языками

Помеченные объединения Rust, discriminated unions TypeScript и алгебраические типы данных выражают тот же подход. Полные решения полезны для сообщений сети, состояний редактора и разобранного синтаксиса.
