# Имена для значений

## Цель

Объявлять переменные с типами и отличать их от констант.

## Объяснение

Переменная даёт имя хранимому значению. В `var apples i64 = 3` тип i64 означает знаковое 64-битное целое число, а 3 — начальное значение. `var` разрешает новое присваивание, `const` — нет. `+=` прибавляет к текущему значению. `bool` хранит true или false, `string` — байты текста. В режиме Learn каждую локальную переменную нужно явно инициализировать. Неиспользуемые имена считаются ошибкой: используйте каждое объявленное значение.

## Пример

```kremen
package main
func main() {
    var apples i64 = 3
    const price i64 = 4
    apples += 2
    println("cost:", apples * price)
}
```

## Задание

Начните с 4 тетрадей, добавьте 3 и посчитайте стоимость по 6 за тетрадь. Выведите `notebooks: 7` и `cost: 42` в отдельных строках. Цена должна быть константой.

## Стартовый код

```kremen
package main
func main() {
    var notebooks i64 = 4
    const price i64 = 6
    println("notebooks:", notebooks)
    println("cost:", notebooks * price)
}
```
