# Повторять с целью

## Цель

Прослеживать цикл и накапливать результат без ошибки на границе.

## Объяснение

Цикл for повторяет блок. Три части задают начальное значение счётчика, проверяют bool перед каждой итерацией и меняют счётчик после неё. В `for number := 1; number <= 5; number++` оператор := объявляет счётчик, а ++ прибавляет единицу. Переменная суммы накапливает результат; её начальное значение задают до цикла. Думайте, что верно перед каждой итерацией и почему цикл закончится.

## Пример

```kremen
package main
func main() {
    var total i64 = 0
    for number := 1; number <= 3; number++ {
        total += number
    }
    println(total)
}
```

## Задание

Сложите все чётные числа от 1 до 10 включительно. Выведите только `30`. Используйте цикл и условие number % 2 == 0.

## Стартовый код

```kremen
package main
func main() {
    var total i64 = 0
    for number := 1; number <= 10; number++ {
        total += number
    }
    println(total)
}
```
