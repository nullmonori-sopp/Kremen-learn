# Внимательно читать ввод

## Подсказки

1. Арифметика нужна только в успешной ветви.

2. Сохраните fail(code) и выводите code напрямую.

3. В ветви ok используйте println("Next:", number + 1).

## Решение

```kremen
package main
func main() {
    var input = readIntResult()
    match input {
        ok(number) => { println("Next:", number + 1) }
        fail(code) => { println("Input error:", code) }
    }
}
```

## Разбор решения

Корректный ввод связывает number; прибавление единицы даёт следующее значение. Ошибка ввода связывает код считывателя, который выводится без изменения. Преобразование через OS errorMessage не используется. Код ошибки потока 4 описан, но переносимые stdin-тесты его не имитируют.

## Связь с другими языками

В любом языке нужно отличать данные от ошибок ввода. Rust возвращает Result при разборе, Go предоставляет ошибки считывателя, Python может выбросить исключение преобразования. Способ передачи различается, но проверка данных и конца ввода необходима.
