# Дать вычислению имя

## Подсказки

1. Квадрат — произведение числа на само себя.

2. Одно выражение должно работать и для положительных, и для отрицательных чисел.

3. Замените return value на return value * value.

## Решение

```kremen
package main
func square(value i64) i64 {
    return value * value
}
func main() {
    println(square(3))
    println(square(5))
    println(square(-4))
}
```

## Разбор решения

У каждого вызова свой параметр value. Произведение двух отрицательных значений даёт положительный квадрат. Мы изменили одно тело функции, и все три вызова используют одно правило.

## Связь с другими языками

Функции позволяют разбивать задачу и проверять части независимо в C, Go, Rust, Java и Python. Явные типы входов и результатов делают договорённости понятными.
