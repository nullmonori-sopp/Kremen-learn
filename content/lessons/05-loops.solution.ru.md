# Повторять с целью

## Подсказки

1. Изменяйте total только внутри условного блока.

2. У чётного числа остаток от деления на 2 равен нулю.

3. Поместите total += number в if number % 2 == 0.

## Решение

```kremen
package main
func main() {
    var total i64 = 0
    for number := 1; number <= 10; number++ {
        if number % 2 == 0 {
            total += number
        }
    }
    println(total)
}
```

## Разбор решения

Цикл посещает десять чисел и прибавляет 2, 4, 6, 8 и 10. Инвариант: total содержит сумму уже посещённых чётных чисел. number каждый раз растёт, поэтому после 10 цикл завершается.

## Связь с другими языками

Накопление результата и инварианты циклов лежат в основе поиска, разбора текста и численных алгоритмов на любом языке. У Go похожий синтаксис for, а Python часто использует range.
