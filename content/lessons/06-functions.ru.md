# Дать вычислению имя

## Цель

Отделять переиспользуемую функцию от вызывающего кода.

## Объяснение

Функция объединяет инструкции под одним именем. Параметры — входные значения, доступные только этому вызову. В `func twice(value i64) i64` последний i64 — тип результата. `return` вычисляет значение и завершает вызов. Каждый путь в функции с результатом должен вернуть подходящее значение. Вызывающий код передаёт аргументы и использует результат. Локальные имена не видны в других функциях.

## Пример

```kremen
package main
func twice(value i64) i64 {
    return value * 2
}
func main() {
    println(twice(21))
}
```

## Задание

Реализуйте square(value i64) i64. Выведите square(3), square(5) и square(-4) по одному результату в строке: 9, 25, 16.

## Стартовый код

```kremen
package main
func square(value i64) i64 {
    return value
}
func main() {
    println(square(3))
    println(square(5))
    println(square(-4))
}
```
