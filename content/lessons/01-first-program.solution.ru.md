# Первая программа

## Подсказки

1. Добавьте вызов внутри фигурных скобок main.

2. Используйте отдельный println для каждой строки.

3. Второй вызов: println("I can program.").

## Решение

```kremen
package main
func main() {
    println("Hello, Kremen!")
    println("I can program.")
}
```

## Разбор решения

Первый вызов печатает приветствие и перевод строки. Второй печатает следующее предложение. Явный символ перевода строки не нужен. Лишняя пустая строка не совпадёт с ожидаемым выводом.

## Связь с другими языками

В большинстве языков есть точка входа и функции вывода: main в C, println! в Rust и print в Python. Названия и знаки различаются, но порядок выполнения остаётся тем же.
