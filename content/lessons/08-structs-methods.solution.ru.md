# Данные и их поведение

## Подсказки

1. Присваивание заменяет поле; сложение должно учитывать прежнее значение.

2. Используйте тот же оператор +=, что и для обычной переменной.

3. Тело метода: counter.value += amount.

## Решение

```kremen
package main
type Counter struct {
    value i64
}
func (counter &mut Counter) add(amount i64) {
    counter.value += amount
}
func main() {
    var counter = Counter{value: 10}
    counter.add(7)
    counter.add(5)
    println("counter:", counter.value)
}
```

## Разбор решения

Получатель &mut меняет исходное поле. Первый вызов даёт 17, второй — 22. Оператор = вместо += оставил бы только последнее переданное число.

## Связь с другими языками

Структуры похожи на записи C и Rust. Методы прикрепляют поведение, как в Go и Rust. Это объединение данных и функций; наследования и интерфейсов в Kremen нет.
