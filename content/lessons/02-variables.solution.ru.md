# Имена для значений

## Подсказки

1. Измените notebooks до вывода.

2. Используйте += для добавления тетрадей.

3. Вставьте notebooks += 3 перед первым println.

## Решение

```kremen
package main
func main() {
    var notebooks i64 = 4
    const price i64 = 6
    notebooks += 3
    println("notebooks:", notebooks)
    println("cost:", notebooks * price)
}
```

## Разбор решения

notebooks меняется с 4 на 7, price остаётся равным 6. Умножение читает текущее значение notebooks, поэтому стоимость равна 42. Присваивание константе price вызвало бы ошибку компиляции.

## Связь с другими языками

Это соответствует изменяемым и неизменяемым привязкам в Rust, let и const в JavaScript и переменным с явными типами в C. Явная разрядность целых важна при обмене двоичными данными.
