# Your first program

## Goal

Run a complete program and control its output.

## Explanation

A program is a sequence of instructions. Kremen begins with `func main()`. Braces enclose its body. `println` prints its arguments with spaces between them and ends the line. Text belongs in double quotes. `package main` identifies this entry module. Calls execute from top to bottom. Try Run first, then edit the text and run again.

## Example

```kremen
package main
func main() {
    println("Hello, Kremen!")
}
```

## Your task

Print `Hello, Kremen!` on the first line and `I can program.` on the second. Match capitalization and punctuation exactly.
