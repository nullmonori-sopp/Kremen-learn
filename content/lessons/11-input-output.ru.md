# Внимательно читать ввод

## Цель

Считывать целое число, сохраняя сведения об ошибке.

## Объяснение

stdin — поток входных байтов, stdout — обычный вывод программы, stderr — диагностика. `readIntResult()` возвращает результат, а не останавливает программу на неверном вводе. Предметные коды считывателя: 1 — конец ввода, 2 — неверный формат, 3 — выход за диапазон i64, 4 — ошибка потока. Это коды считывателя, не OS errno. В приложении заполните stdin перед запуском; тесты независимо подставят свой ввод. Learn требует безопасный ввод целого с обработкой обоих случаев.

## Пример

```kremen
package main
func main() {
    var input = readIntResult()
    match input {
        ok(number) => { println("Read:", number) }
        fail(code) => { println("Input error:", code) }
    }
}
```

## Задание

Считайте целое число. При успехе выведите `Next:` и число плюс один. При неудаче выведите `Input error:` и настоящий код считывателя. Не выводите приглашение. Тесты проверяют положительное и отрицательное число, неверный формат, конец ввода и выход за диапазон.

## Стартовый код

```kremen
package main
func main() {
    var input = readIntResult()
    match input {
        ok(number) => { println("Next:", number) }
        fail(code) => { println("Input error:", code) }
    }
}
```
