# Вычислять и сравнивать

## Цель

Получать значения с помощью арифметики, сравнений и скобок.

## Объяснение

Выражение производит значение. Умножение и деление выполняются до сложения и вычитания; скобки меняют порядок. Целочисленное деление отбрасывает дробную часть: 17 / 5 равно 3. Оператор остатка % даёт 2. `==` сравнивает значения, а `=` присваивает их. Сравнения возвращают bool. Арифметика и преобразования целых защищены проверками во время выполнения; деление на ноль — ошибка.

## Пример

```kremen
package main
func main() {
    println(2 + 3 * 4)
    println((2 + 3) * 4)
    println(17 / 5, 17 % 5)
}
```

## Задание

Для 23 учащихся нужны столы на 4 человека. Выведите число полных столов, оставшихся людей и ответ, можно ли рассадить всех без неполного стола: `5`, `3`, `false`. Используйте /, % и ==.

## Стартовый код

```kremen
package main
func main() {
    const learners i64 = 23
    const seats i64 = 4
    println(learners)
    println(seats)
}
```
