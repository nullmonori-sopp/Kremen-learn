# Выбрать путь

## Подсказки

1. 82 находится между 60 и 89.

2. Добавьте else if между первым if и последним else.

3. Используйте else if score >= 60 { println("passed") }.

## Решение

```kremen
package main
func main() {
    const score i64 = 82
    if score >= 90 {
        println("excellent")
    } else if score >= 60 {
        println("passed")
    } else {
        println("try again")
    }
}
```

## Разбор решения

82 не проходит первое сравнение и проходит второе, поэтому выводится только passed. Самостоятельно проверьте граничные значения 59, 60, 89 и 90: так станет понятна важность порядка.

## Связь с другими языками

Ветвление есть в большинстве языков. Такая классификация применяется в проверке данных, переходах состояния интерфейса и обработчиках протоколов. Проверка границ полезна и в больших программах.
