# Вычислять и сравнивать

## Подсказки

1. Частное и остаток отвечают на разные вопросы.

2. Выведите learners / seats, затем learners % seats.

3. Сравните остаток с нулём оператором ==.

## Решение

```kremen
package main
func main() {
    const learners i64 = 23
    const seats i64 = 4
    println(learners / seats)
    println(learners % seats)
    println(learners % seats == 0)
}
```

## Разбор решения

23 = 5 × 4 + 3. Пять столов заполнены, трое учащихся остаются. Остаток не равен нулю, поэтому последнее сравнение даёт false.

## Связь с другими языками

Целочисленное деление, остаток, приоритет операций и логические сравнения есть в C, Java, Go и Rust. Python использует // для целочисленного деления: при смене языка проверяйте синтаксис.
