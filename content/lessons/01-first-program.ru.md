# Первая программа

## Цель

Запустить целую программу и управлять её выводом.

## Объяснение

Программа — последовательность инструкций. Kremen начинает с `func main()`. Фигурные скобки ограничивают её тело. `println` выводит аргументы через пробел и заканчивает строку. Текст заключают в двойные кавычки. `package main` обозначает главный модуль. Вызовы выполняются сверху вниз. Сначала запустите пример, затем измените текст и запустите снова.

## Пример

```kremen
package main
func main() {
    println("Hello, Kremen!")
}
```

## Задание

Выведите `Hello, Kremen!` в первой строке и `I can program.` во второй. Сохраните регистр и знаки препинания.
