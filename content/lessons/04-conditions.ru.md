# Выбрать путь

## Цель

Принимать взаимоисключающие решения по логическим условиям.

## Объяснение

Блок if выполняется только при истинном условии. else if проверяет следующее условие, если первое не подошло; else обрабатывает оставшиеся случаи. Условие должно иметь тип bool. `>=` означает «не меньше». `&&` требует выполнения обоих условий, `||` — хотя бы одного, а `!` обращает bool. Порядок важен: широкое первое условие может скрыть более точный случай.

## Пример

```kremen
package main
func main() {
    const temperature i64 = 12
    if temperature < 0 {
        println("freezing")
    } else {
        println("above freezing")
    }
}
```

## Задание

Для оценки 82 выведите `excellent`, если она не меньше 90, `passed`, если не меньше 60, иначе `try again`. Должна появиться одна строка. Сохраните все три ветви.

## Стартовый код

```kremen
package main
func main() {
    const score i64 = 82
    if score >= 90 {
        println("excellent")
    } else {
        println("try again")
    }
}
```
