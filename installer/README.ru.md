# Собственный офлайн-установщик

Установщик для Linux написан на C++17. К его ELF-файлу добавлен архив POSIX
ustar. Во время установки не нужны сервер, права администратора, Python,
Node.js, программа распаковки или криптографическая библиотека. Для сборки
установщика нужны C++17-компилятор, GNU tar и sha256sum.

Перед распаковкой установщик проверяет весь архив по SHA-256, записанному в
скомпилированной программе. Встроенный читатель архива проверяет контрольные
суммы заголовков, запрещает абсолютные пути, `..`, ссылки, специальные файлы и
управляющие символы. Файлы распаковываются только в новый закрытый временный
каталог. Права запуска сохраняются; setuid, setgid и запись для других
пользователей отбрасываются. Хеш обнаруживает повреждение, но сам установщик
нужно получать из доверенного источника. В первой версии цифровой подписи нет.

Сборка после `npm run package`:

```sh
./scripts/build-installer.sh
```

Первым необязательным аргументом можно передать каталог готового комплекта,
вторым — путь итогового файла. В комплект должны входить:

```text
kremen-learn
toolchain/bin/kremen
toolchain/runtime/kremen_rt.h
content/catalog.json
```

Установщик проверяет наличие GCC, Bubblewrap и WebKitGTK 4.1. Эти системные
компоненты не включены в комплект, не скачиваются и не устанавливаются
автоматически. Отчёт о зависимостях носит информационный характер: можно
установить приложение до того, как администратор добавит недостающие пакеты.
Панель тулчейна внутри приложения показывает фактическую готовность компиляции
и изоляции.

Запуск:

```sh
chmod +x Kremen-Learn-0.1.0-linux-x86_64.run
./Kremen-Learn-0.1.0-linux-x86_64.run
```

Флаг `--yes` включает установку без вопросов; `--check` выводит зависимости;
`--verify` проверяет архив без установки; `--prefix /абсолютный/путь` выбирает
другой пользовательский каталог. Системная установка для всех пользователей
не предусмотрена.

По умолчанию создаются:

```text
~/.local/share/kremen-learn/releases/<версия>-<хеш>-<идентификатор-процесса>/
~/.local/bin/kremen-learn
~/.local/share/applications/org.kremen.learn.desktop
```

Команда запуска — символическая ссылка на установленную программу. Каждая
установка получает отдельный каталог выпуска; старые выпуски хранятся до
удаления приложения. Они не являются резервными копиями прогресса или проектов.
Повторная установка переключает команду запуска на новый проверенный выпуск.

Для удаления используйте тот же установщик:

```sh
./Kremen-Learn-0.1.0-linux-x86_64.run --uninstall
```

Удаляются только помеченный каталог приложения и принадлежащие установщику
команды запуска. Отдельный каталог данных приложения и проекты в других местах
сохраняются. Если при установке использовался `--prefix`, передайте его снова.

В этом выпуске установщика для Windows нет. Linux-программа не является
Windows-пакетом; Windows и WSL требуют отдельной реализации и проверки.

Команда `python3 installer/test_installer.py` проверяет установщик отдельно.
Тест собирает настоящие программы установки и проверяет каталог с пробелами и
специальными символами оболочки, запуск, переустановку, удаление с сохранением
данных, отказ при повреждении архива, попытках выхода из каталога, абсолютных
путях и символических ссылках. Используется небольшой тестовый исполняемый файл;
запуск установленного настольного приложения проверяется отдельно перед выпуском.
